🚀 JavaScript Projects

A collection of beginner-friendly JavaScript projects built to strengthen my understanding of JavaScript fundamentals, DOM manipulation, event handling, and working with APIs.

This repository contains three projects developed while learning JavaScript and applying concepts through practical implementation.

📂 Projects

1. 🎮 Tic Tac Toe

A classic Tic Tac Toe game built using HTML, CSS, and JavaScript.

Features

* Interactive 3 × 3 game board.
* Two-player gameplay.
* Win detection based on predefined winning combinations.
* Draw detection when all cells are filled without a winner.
* Reset and new game functionality.

Concepts Learned

* DOM manipulation.
* Event handling using addEventListener().
* Selecting elements using querySelector() and querySelectorAll().
* Updating HTML content using innerText.
* Managing game state using JavaScript variables.
* Conditional statements, arrays, and loops.

Technologies: HTML, CSS, JavaScript

📁 Folder: tic_tac_toe

⸻

2. ✊ Rock Paper Scissors (SPS)

A Rock Paper Scissors game where the user plays against the computer.

Features

* Interactive Rock, Paper, and Scissors choices.
* Random computer selection.
* Automatic winner determination.
* User and computer score tracking.
* Dynamic game messages.

Concepts Learned

* DOM manipulation.
* Event handling and click interactions.
* Using Math.random() for computer choices.
* Conditional statements and functions.
* Updating scores dynamically.
* Comparing user and computer choices.
* Updating webpage content using JavaScript.

Technologies: HTML, CSS, JavaScript

📁 Folder: sps

⸻

3. 💱 Currency Converter

A currency converter that calculates conversions between supported currencies using exchange-rate APIs.

Features

* Dynamic currency dropdowns.
* Default currencies: USD and INR.
* Country flags that update when currencies change.
* Currency swapping functionality.
* Automatic exchange-rate calculation on page load.
* Manual conversion using the exchange-rate button.
* Primary and fallback API endpoints.
* Error handling for unavailable exchange rates.

Concepts Learned

* DOM manipulation and dynamic element creation.
* Working with JavaScript objects.
* Fetching data from external APIs using fetch().
* Asynchronous JavaScript using async and await.
* Handling Promises and JSON responses.
* Template literals and dynamic URL construction.
* Event handling for dropdowns and buttons.
* Error handling using try...catch.
* Input validation and mathematical calculations.

Technologies: HTML, CSS, JavaScript, Currency Exchange API, Flags API

📁 Folder: currency_converter

▶️ How to Run the Projects

1. Clone this repository:

git clone https://github.com/Raj-18-45-/js-projects.git

2. Open the repository folder in VS Code.
3. Open the index.html file inside the project you want to run.
4. Run the project using a browser or the VS Code Live Server extension.

Note: The Currency Converter requires an internet connection to fetch exchange rates and load flag images.
